# Governance Objectives & Requirements

## Objectives
- Enforce least privilege access
- Ensure periodic access validation
- Protect privileged roles

## Governance Requirements
- Quarterly access reviews
- Just-In-Time privileged access
- Centralized audit logging

## Compliance Mapping
| Control | Framework |
|------|-----------|
| Access Reviews | ISO 27001 A.9 |
| PIM | NIST AC-6 |
| Audit Logs | GDPR Article 30 |
