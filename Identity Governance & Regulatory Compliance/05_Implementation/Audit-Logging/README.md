# Audit Logging & Monitoring

## Objective
Provide visibility into identity-related actions for compliance and investigations.

## Tasks Performed
- Review sign-in logs
- Review audit logs
- (Optional) Validate log retention settings to Log Analytics Workspace

## Validation
- Logs available for admin actions
- Logs usable for audits

## Evidence to Capture
- Sign-in log screenshots
- Audit log screenshots
