# Privileged Identity Management (PIM)

## Objective
Eliminate standing admin privileges by enforcing Just-In-Time access.

## Tasks Performed
- Enable PIM
- Configure eligible admin roles
- Require:
  - MFA
  - Approval
  - Time-bound access

## Validation
- Role activation successful
- Audit logs generated

## Evidence Captured
- PIM role settings
- Activation logs
