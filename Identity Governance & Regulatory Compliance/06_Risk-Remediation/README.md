# Risk Identification & Remediation

## Identified Risks
- Over-privileged users
- Inactive accounts with access
- Permanent admin role assignments

## Remediation Actions
- Enabled access reviews
- Enforced PIM
- Removed unnecessary access

## Compliance Alignment
Evidence supports:
- ISO 27001 access control requirements
- NIST access governance controls

## Outcome
Reduced identity risk and improved audit readiness.
