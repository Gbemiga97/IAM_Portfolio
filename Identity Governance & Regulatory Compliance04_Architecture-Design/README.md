# Identity Governance Architecture

## Architecture Overview
Microsoft Entra ID serves as the centralized identity provider with built-in governance controls.

## Components Used
- Entra ID Identity Governance
- Access Reviews
- Privileged Identity Management
- Audit Logs

## Design Goals
- Centralized access control
- Minimal standing privilege
- Audit-ready identity events

- Designed identity governance architecture for Microsoft Entra ID
- Visualized access control, PIM, and access review flows
